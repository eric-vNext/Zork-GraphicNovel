# Final Build Report — Zork I: The Great Underground Empire, Graphic Novel Edition

**Phase 6 deliverable.** A playable, browser-based, illustrated port of Zork I, built from the
[historicalsource/zork1](https://github.com/historicalsource/zork1) ZIL release (vendored at `reference/zork1-source/`).

## What was built

A **native TypeScript reimplementation** of the Zork I engine (per the decision in `docs/research-report.md`),
wrapped in a motion-comic presentation layer:

- **World data extracted mechanically from the ZIL source**: all **110 rooms** and **~140 objects**
  (descriptions, exits with all five conditional forms, synonyms/adjectives, flags, sizes, capacities,
  VALUE/TVALUE) live in `game/src/data/world.gen.json`, generated by a ZIL parser
  (scratchpad `extract_world.py`). Room text is verbatim; the 23 rooms with routine-generated
  descriptions (Living Room, dam, reservoirs, Hades, …) are hand-ported in `specialDescs.ts`.
- **Parser** (`src/parser/parse.ts`): verb-noun grammar with prepositions, adjectives,
  disambiguation questions (answers become tappable chips), orphaning ("What do you want to open?"),
  `ALL`/`AND`/`ALL BUT`, `IT`, `AGAIN`/`G`, abbreviations (`n s e w ne nw se sw u d l x i z`),
  local-over-global noun preference.
- **Engine** (`src/engine/`): ZIL-order action dispatch (room M-BEG → indirect-object action →
  direct-object action → default verb), the gclock daemon table (lamp 100/70/15 fuel stages,
  candles 20/10/5, match 2, thief, fight, sword-glow, cure 30, cyclops rage, reservoir fill/empty 8,
  maintenance flood 13, river drift, forest songbird, exorcism timers), combat with randomized melee
  outcomes and villain retaliation, the thief's wander/steal/deposit/egg-opening AI, `JIGS-UP`
  death with -10 penalty, item scattering, two resurrections and permanent third death,
  grue darkness rules, load limits (100), and full scoring: take values, case values (nested
  containers counted, per OTVAL-FROB), 4 scored rooms, and the 13-point Drafty-Room light bonus —
  **totalling exactly 350**.
- **All major puzzles**: mailbox, kitchen window, rug/trap door (slams until the thief dies),
  troll, maze + skeleton loot + grating, cyclops (lunch/water or ODYSSEUS), thief & egg/canary/bauble,
  chimney 2-item limit, dam bubble/bolt/reservoir drain, blue-button flood (+ gunk repair),
  Loud Room ECHO, rope/dome/torch, bell-book-candles exorcism (hot bell drops your candles, timed
  windows), prayer teleport, coffin/sceptre, solid rainbow + pot of gold, boat inflation/launch/
  drift/puncture-by-sharp-objects, buoy emerald, sandy-cave scarab (dig 4, die on 5), bat + garlic,
  gas-room explosion, basket/coal/machine/diamond, slide ride home, map + Stone Barrow victory.
- **Presentation**: Framer Motion panel fade/fly-in (420 ms rooms / 600 ms events, ease-out-quint,
  interruptible), 116 original AI-illustrated panels with state variants, comic caption plates,
  clickable compass + up/down, quick-command chips, score/moves/health-lantern status,
  Howler.js crossfaded region music (10 original synthesized beds incl. a layered Hades drone)
  and 33 original synthesized SFX, persisted mute, localStorage save/restore + JSON export/import,
  title/death/victory screens, help modal.

## How to run

```bash
cd game
npm install
npm run dev        # http://localhost:5173
npm run build      # static production build in game/dist (deployable anywhere)
npm test           # 11 tests incl. a complete 350/350 playthrough
```

## File structure

```
game/
  index.html                  viewport/meta (interactive-widget=resizes-content)
  scripts/convert-assets.py   masters -> WebP (public/art, 24 MB)
  scripts/synth-audio.py      numpy DSP -> WAV masters + AAC delivery (public/audio, 7 MB)
  src/
    data/world.gen.json       extracted rooms/objects (verbatim source text)
    data/presentation.ts      room->panel/region map, music map, panel fallbacks
    parser/parse.ts           grammar, vocabulary, disambiguation
    engine/                   world model, verbs, specials (puzzles), daemons,
                              combat/thief, death, dynamic descriptions, main loop
    state/store.ts            Zustand presentation state (log, panel, region, chips)
    audio/audioManager.ts     Howler beds + SFX, crossfade + debounce
    components/, App.tsx      React UI (stage/log/command bar/screens)
  tests/walkthrough.test.ts   opening, grue, troll, scoring, parser, dam, exorcism, saves
  tests/fullrun.test.ts       BFS-navigated full 350-point completion run
```

## Controls

Type commands (`open mailbox`, `n`, `take lamp`, `attack troll with sword`, `put coffin in case`).
Enter submits; ↑/↓ recalls history. Tap the compass or ▲▼ for movement; chips for common commands;
disambiguation answers appear as chips. Status bar: Inventory, Save, Restore, Mute, Help.
Chips/compass fire on `pointerdown` so the mobile keyboard never bounces; the panel compresses when
the keyboard opens (`interactive-widget=resizes-content` + height media query).

## Verification performed

- `tsc --noEmit` clean; `vite build` clean; zero browser console errors.
- 11 automated tests, including a **complete 350/350-point playthrough** (376 moves) that
  navigates via BFS over the real exit graph and fights with era-authentic save-scumming.
- Manual browser playtest (desktop + 375×812 mobile): title → opening → cellar → troll fight,
  panels/music/SFX/chips/status verified; no missing-asset 404s.
- Fidelity traps confirmed live: dark attic grue death, gas-room explosion with a carried flame,
  trap-door slam, thief robbery, lamp burnout after ~185 lit turns, load-limit haul planning.

## Known limitations

- ~60 low-traffic verb responses use faithful-flavored defaults rather than the exact original
  string for every object (all iconic responses are verbatim).
- Melee tables are simplified (weighted outcome tiers rather than the full per-villain DEF tables);
  balance approximates the original.
- Some Tier-2 art variants aren't generated (e.g., trophy-case-full); the engine falls back cleanly.
- The Loud Room echo gag covers commands coarsely; `OOPS`, `WAIT n`, and `SCRIPT` are not implemented.
- Thief encounters use appearance probabilities rather than true room-graph pathing.
- Save format is JSON (export/import supported), not Quetzal.
